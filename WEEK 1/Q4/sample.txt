NOTES
--------------------------------------------------------------
* The Simulated and Formula columns match for all 25 rows.
  T(n) = 2*T(n-1) + 1, T(0) = 0  solves to  T(n) = 2^n - 1.
* Each extra disc doubles the work: 3 discs need 7 moves,
  4 need 15, and 25 need 33,554,431.
* The exponential cost is a lower bound of the problem, not a
  weakness of this implementation: producing 2^n - 1 moves takes
  at least 2^n - 1 steps.
* The real ASCII graph uses a solid block character; '#' is
  substituted here for plain-text portability.
* The program writes toh.csv into the current working directory.
  Run it from a scratch directory if you do not want the
  committed copy overwritten.
