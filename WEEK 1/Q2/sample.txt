============== CONCLUSION ==============
1. A fair coin converges towards probability 0.5.
2. A biased coin converges towards its own probability.
3. Increasing the number of tosses reduces random error.
4. This demonstrates the Law of Large Numbers.

Time Complexity  : O(n)
Space Complexity : O(1)

--------------------------------------------------------------
NOTES
--------------------------------------------------------------
* rand() is seeded with time(NULL), so exact counts differ on
  every run.  What reproduces is the convergence, not the digits.
* The error shrinks roughly as 1/sqrt(n): one extra decade of
  tosses buys only about HALF a correct digit, and gaining a
  full digit takes 100x the samples.  Monte Carlo convergence
  is slow.
* Each biased coin converges to its OWN probability, not to 0.5.
* The real ASCII graph uses a solid block character; '#' is
  substituted here for plain-text portability.
* The program writes coin_toss_analysis.csv into the current
  working directory.  Run it from a scratch directory if you do
  not want the committed copy overwritten.
