# Q1 — Binary Search vs Ternary Search

> Search for an element `x` in a sorted list of `n` elements. Compare binary
> search (two intervals per level) against ternary search (three intervals).

## Problem Statement

Let `x` be an element stored in a sorted list `L` of `n` elements.

**(a) Binary search:** split the interval in two. One comparison tells which
half to keep.

**(b) Ternary search:** split the interval in three. Up to four comparisons
are needed to decide which third to keep.

Write a program for both and empirically compare the number of key comparisons
as a function of `n`.

---

## The Analysis

### Binary search — 2 log₂ n

One mid-point is compared against x (1 comparison). That decides which half
to keep. The recurrence is:

```
T(n) = T(n/2) + 2,   T(1) = 1
```

which solves to:

```
T(n) = 2 ⌈log₂ n⌉
```

### Ternary search — 4 log₃ n

Two cut-points m₁ and m₂ are compared against x (up to 4 comparisons).
The recurrence is:

```
T(n) = T(n/3) + 4,   T(1) = 0, T(2) = 3
```

which solves to:

```
T(n) = 4 ⌈log₃ n⌉
```

### Why ternary is worse

```
4 log₃ n  vs  2 log₂ n
= 4 (log₂ n / log₂ 3)  vs  2 log₂ n
= (4 / log₂ 3) log₂ n   vs  2 log₂ n
≈ 2.52 log₂ n            vs  2.00 log₂ n
```

Ternary does ~26% more comparisons. The three-interval split only saves
one recursive step per two binary steps, but each step costs twice as much
comparisons. The trade-off never pays off.

```
Binary  : 2 comparisons per level, log2(n) levels  -> 2*log2 n
Ternary : 4 comparisons per level, log3(n) levels  -> 4*log3 n
Ratio   : 4*log3 n / 2*log2 n = 2*log(2)/log(3) = 1.2619
So ternary does about 26% more comparisons: binary is better.
```

### Reading the output

**wc/log2 n is flat at 2.00 at every size** — this is the exact form of the
binary worst case, not an asymptotic approximation. The worst case for binary
is always exactly `2 ⌈log₂ n⌉`, and when n = 2ᵏ − 1 every probe lands on
a mid-point that requires the maximum number of levels.

**The ratio column (ter avg / bin avg) is stable around 1.15–1.24.** The
average for ternary isn't quite at the 1.26 ratio of the worst case because
the random probes sometimes land in the first or last third (1–2 comparisons)
rather than the middle third (4 comparisons), pulling the average down slightly.

**Binary wins in every regime** — both average and worst case, at every size.
